# 📡 TFTP – Trivial File Transfer Protocol

## 📌 Project Overview
Developed a TFTP client-server application using C programming and UDP sockets to transfer files between systems over a network. The project demonstrates network communication, packet handling, and reliable file transfer.

## ✨ Key Features
- Client-server communication using UDP sockets.
- File upload and download functionality.
- TFTP packet handling (RRQ, WRQ, DATA, ACK, ERROR).
- Block-wise file transfer with acknowledgements.
- Error handling and packet retransmission.

## 🛠️ Technologies Used
C Programming, Linux (Ubuntu/WSL), UDP Socket Programming, and Network Programming.

## 🔄 Working Flow
The client sends a read or write request to the server. The server processes the request and transfers file data in blocks, using acknowledgements to manage the transfer.

## 🧠 Key Challenges & Learning
1. Understanding the TFTP protocol and packet structure.
2. Implementing client-server communication using UDP sockets.
3. Handling acknowledgements, packet errors, and reliable file transfer.

## 🎯 Project Objective
To gain practical experience in network programming and understand how file transfer protocols work using UDP-based client-server communication.
